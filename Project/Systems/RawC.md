### Welcome

Welcome to the Raw and Primitive C Typed Objects System's documentation page. This page is dedicated to helping you understand the system and its features. However please note that for understanding how to use the project you should check out [Learning][Page Learn Home] for all the dedicated learning for the given project.

### System Details

- Details
	- Name: Raw and Primitive C Typed Objects
	- SystemID: LibCore.RawC
	- IDPiece: RawC
	- Version: V 0.2.0
	- Implimented Version: V D 0.0.26.0
	- Last Changed: V D 0.0.26.0
	- Tags
		- [CodeLanguage: C]
		- [OOP: RawC]
		- [OOP: Primitive]
		- [OOP: HotSwapEnabled]

This specialized system provides two step typed handling. The first being Primitive C Data Type (PrimBool,PrimUInt64). The second being Raw C Object Types which are a parented based structured object with a function pointers to allow OOP style calling. Both expect to be manual released. Please do keep this in mind.
